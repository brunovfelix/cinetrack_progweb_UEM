## Como rodar o backend

Em um terminal:

```powershell
cd backend
npm install
Copy-Item .env.example .env
npm run dev
```

O backend usa a porta `3000`, definida em `backend/.env`.

## Como rodar o frontend

Em outro terminal:

```powershell
cd frontend
npm install
npm run dev
```

Abra o endereço exibido pelo Vite (por padrão, `http://localhost:5173`).
